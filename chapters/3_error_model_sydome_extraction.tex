\chapter{Error Models and Fault Tolerance}\label{ssec:error_models}

We previously assumed that errors only happen at a specific point in our quantum circuit, namely before we extract the syndrome.
A more realistic model would assume that errors can occur in every part of the circuit, with every gate applied, measurement taken and on each initialized individual qubit, and therefore also during the syndrome extraction.
We will refer to this more realistic as the \emph{circuit-level} noise model, and we will define it in more detail in section \ref{sssec:circuit_level_noise}. 
The model where errors only appear after the state preparation on the data qubit is called the \emph{code-capacity} noise model.

The threshold of the QEC code depends significantly on the choice of the error model.
In this subsection we will introduce the two different error models uses in this thesis.


\section{Code-Capacity Noise Model}\label{sssec:code_capacity_error_model}

For the \emph{code-capacity} noise model we apply independent errors onto the data qubits after we have encoded the logical qubits.
There are no other locations in the circuits where errors occur.
The placement in the circuit is visualized in figure \ref{circ:code_capacity_noise}.
As such we implicitly assume that all gates in the encoding, syndrome extraction and associated ancilla qubits and measurements are faultless.
This is the simplest noise model \cite{mld_decoding_intro_luis}. 

This model can be realized by applying a depolarizing, bit-flip or phase-flip noise channels. 
We will implement it by either applying a bit flip ($X$) noise channel on each data qubit after encoding the logical $\ket{0}_L$ state, in cases where we measure the logical $\bar{Z}$ observable at the end of the circuit.
When we measure the logical $\bar{X}$ at the end of the circuit, we will apply a phase flip ($Z$) error onto the data qubits after initializing the logical $\ket{+}_L$ state.

Both noise channel, $\varepsilon_X(\rho)$ is the bit-flip and $\varepsilon_Z(\rho)$ is the phase-flip error channel, are proportional to $p_{phy}$, taking the form on each data qubit 
\begin{align}
    \varepsilon_{X}(\rho) = (1-p_{phy}) \rho + p_{phy} \cdot X \rho X \label{eq:bit_flip_channel}\\
    \varepsilon_{Z}(\rho) = (1-p_{phy}) \rho + p_{phy} \cdot Z \rho Z \label{eq:phase_flip_channel}.
\end{align}

\section{circuit-level Noise Model}\label{sssec:circuit_level_noise}

The second and more complex noise model we will use is the so called \emph{circuit-level} noise model.
This is designed to be more realistic, as we model all gates, measurements and qubits to be faulty.
Here we assume for simplicity that each elementary gate and measurement can fail independently, each with the error probability $p_{phy}$. 

In general one assigns errors to every operation which include state preparation, single- and two-qubits gates and measurements\footnote{
It is also common to include idling errors, errors on qubits not acted on.
But due to the construction of our circuit we decided against using those.
}.
This means that our whole decoding process is faulty as well.

To implement this error model we use the following error channels:
We simulate measurement errors by placing a bit- or phase-flip channel (eq. \ref{eq:bit_flip_channel} and eq. \ref{eq:phase_flip_channel} respectively) onto measured qubits before the measurement.
Here we choose bit-flip errors before $Z$ measurement and phase-flip errors before $X$ measurement to simulate the measurement failing.

For two qubit gates we apply two qubit depolarizing noise $\varepsilon_{D_2}$ on both qubits, $q1$ and $q2$, acted upon by the gate 
\begin{equation}
    \varepsilon_{D_2}(\rho) = (1-p_{phy}) \rho + \frac{p_{phy}}{15} \sum_{i=1}^{15} E_i \rho E_i,
\end{equation}
with
\begin{equation}
    E_i \in \{E_{q1} \otimes E_{q2} | E_k,E_l \in \{I,X,Y,Z\} \} \setminus \{I\otimes I \}.
\end{equation}
Here in contrast to the measurement noise channel we place the noise channel after the two qubit gate. 

After initialization of each qubit we place a depolarizing one qubit noise channel $\varepsilon_{D_1}$ on each qubit
\begin{equation}
    \varepsilon_{D_1}(\rho) = (1-p_{phy}) \rho + \frac{p_{phy}}{3} \sum^3_{i=1} E_i \rho E_i,\  E_i \in \{ X, Y, Z \}.
    \label{eq:depo_1_noise}
\end{equation}

In this thesis we assume that we have access to fault-tolerantly prepared logical encoded states.
As such we do not model the state preparation of those states completely, but just encoded them noiseless and then place independent depolarizing noise on each qubit of the resulting state to mimic a fault-tolerant encoding procedure.
We choose to assume that because the fault-tolerant preparation for arbitrary distance codes is for itself a hard task to realize.

We can already state that only fault-tolerant QEC codes show distance preserving properties under this error model, and we will introduce the concept of fault tolerance in section \ref{sec:fault_tolerance}.
Note here that these errors propagate through the circuit, as we will discuss in the following section \ref{ssec:cnot_gate}, during the QEC cycle, which leads to correlated errors being spread over multiple qubits.

\subsection{CNOT Gate}\label{ssec:cnot_gate}

Error do not only appear in the circuit at fixed position they also propagate through the circuit as shown by the example of the \emph{CNOT gate}. 

It is a two qubit gate and implements the controlled NOT operation.
Especially important for the use case in this paper is how this gates propagates errors $E$ \cite{gottesmann_book}.
As the CNOT operation is unitary and hermitian we can write
\begin{equation}
    \text{CNOT} \ E\ket{\Psi} = \text{CNOT } E\text{ CNOT} \ \text{CNOT} \ket{\Psi}.
\end{equation}
The propagated error is therefore $\text{CNOT } E \text{ CNOT}$.
We can identify that an error acting only on the first qubit of the CNOT gate $E = X \otimes I$, will be propagated to become a error acting on both qubits $X \otimes X$.
Here the first element of the tensor product is the error acting on the control qubit and the second is acting on the target qubit of the CNOT gate. 
As such the CNOT gate propagates $X$-type errors from the control bit onto the target bit. 
% Show a circuit diagram for CNOT gates!

We can identify such a propagation also in the other direction.
$E = I \otimes Z$, will become $Z \otimes Z$, which tells us that $Z$-type errors propagate from the target qubit onto the control qubit.

Even if the CNOT gate itself is not faulty, an error propagated through a CNOT gate, can lead to an increase in the total number of errors present in the circuit. 
And given that errors can occur at all possible locations in the circuit we need to design the circuit carefully to keep the propagation of errors under control, which will be formalized in the next section about fault tolerance.

We will later show that we can use this error propagation property of CNOT gates to our advantage in chapter \ref{ssec:syndrome_extraction}. 


\subsection{Fault Tolerance}\label{sec:fault_tolerance}

At this point we introduce the notion of \emph{fault tolerance} (FT) QEC circuits, to formalize the property of controlled propagation of errors in those circuits.
A fault-tolerant circuit design is a necessary condition for a threshold to exist for the given QEC code under circuit-level noise (see section \ref{ssec:threshold_theorem}).
Notice that fault tolerance is a property of the circuit. 
We can implement the same QEC code, the surface code for example, both in a FT and non FT circuit, depending of the design of the circuits implementing the different parts\footnote{
    Those parts are for example state preparation, syndrome extraction, logical operations.
    In this thesis we focus on the FT syndrome extraction, while assuming that we have access to FT logical state preparation for encoded ancilla qubits.
    } of the QEC circuit.

We derived for the code-capacity case that a QEC code with code distance $d$, is able to correct $t$ errors (see section \ref{sssec:distance_stabilizer_formalism}).
Given that for the circuit-level noise model error can occur in every part of the circuit, 
and that errors happening on one qubit can be propagated onto multiple qubits through CNOT gates for example (see section \ref{ssec:cnot_gate}), 
we need to introduce the fault-tolerant condition to retain the same relation between the distance $d$ and the number of correctable errors $t$. 

We therefore define a circuit as fault-tolerant, under a given error model, if $t$ independent errors during the cycle end up as a residual error which is still correctable.
Which is equivalent to saying that a FT circuit is designed, such that at least $t+1$ independent errors need to occur, to produce a logical operator on the encode code block.
If there is a single error event which leads to a reduction in the effective weight of the logical operator\footnote{
    Here we use the term effective weight of the logical operator, to refer to refer to the number of independent error events needed to realize this logical operator.
} of the QEC code is not fault-tolerant \cite{friederike_steane,gottesmann_book}.

As an example circuit is trivially fault-tolerant, if each error event leads to at most one error per logical encoded code block\footnote{A code block is the unit encoded by a single QEC code, so in our case a single qubit}.
This will be the case for the steane type syndrome extraction circuit (see section \ref{sssec:steane_type_error_correction_intro}). 

But, as shown in section \ref{sssec:standard_syndrome_extraction_circuit} where we discuss hook errors for the conventional syndrome extraction circuit, 
single errors events, propagating onto multiple qubits of an encoded code block, do not necessary break fault tolerance,
if the propagated error do not lead to a effectively reduced weight of the logical operators of the QEC code.

Applying the concept of fault tolerance to a complete QEC cycle, including the recovery, we can identify that our condition for a successful recovery changes.
Instead of requiring that the QEC cycles recovers the original logical state perfectly for a successful recovery, 
we only require that the QEC cycles recovers the original logical state up to a correctable residual error\footnote{
    The need to redefine the condition for a successful recovery becomes obvious, if we take into account, that for the circuit-level noise model each operation is noisy. 
    Therefore the last operation can introduce an error, and given that we have no way to detect this last error, because it happened by definition after all operation on the circuits are concluded,
    we can not detect or remove it. 
}. 

To implement this adapted success condition in our simulation we will perform a noiseless round of syndrome extraction and decoding after the last QEC cycle to be able to correct the residual error before measuring the observable. 
We will refer to this syndrome extraction as the FT syndrome extraction, and to the decoder as FT decoder.
